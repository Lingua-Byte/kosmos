# Referências do autor (só no PC)

Ponha aqui os PDFs e livros que o Claude deve ler para aprender a escrever: roteiros, livros de narrativa de jogos,
romances. O git ignora tudo nesta pasta, menos este arquivo. Os livros não vão para o GitHub, porque o repositório
do jogo é público.

Para o Claude ler, abra o Claude Code no PC, na pasta do projeto, e peça: "leia o PDF tal em referencias/".
PDF com mais de 100 páginas não é problema: ele lê em partes.

O que for aprendido entra no `GUIA_ESCRITA.md` (seção 6), que vale para todas as sessões, inclusive as do Android.
